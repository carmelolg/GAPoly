# Logo

Metti qui il logo con questi nomi (il sito li trova da solo, non serve toccare il codice):

| file | uso |
|---|---|
| `logo.svg` (oppure `logo.png`, `logo.webp`) | logo nell'intestazione; se ci sono più formati vince il primo in questo ordine |
| `favicon.png` (oppure `favicon.svg`, `favicon.ico`) | icona della scheda del browser; se manca si usa il logo |

Senza logo l'intestazione mostra solo il titolo di `site.json`.
Consiglio: logo con sfondo trasparente, alto almeno 120 px (il sito lo mostra a ~36 px), leggibile su fondo chiaro e scuro.
